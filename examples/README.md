# Ejemplo únicamente ficticio

Para generar un Excel de ejemplo con datos imaginarios, ejecuta desde la raíz del proyecto tras instalar las dependencias:

```bat
set "PYTHONPATH=%CD%\src"
.venv\Scripts\python.exe -m trazabilidad.cli plantilla --output ".local\ejemplo_ficticio.xlsx" --ejemplo-ficticio
```

Ningún dato real, nombre de productor, coordenada productiva, credencial ni URL del formulario se distribuye aquí. El ejemplo generado **no debe enviarse** al formulario real.
